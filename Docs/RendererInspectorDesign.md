# Horizon Renderer 运行时检查工具设计

F1 Inspector 独立窗口、实体列表、反射组件编辑和 CVar 命令行已接入 Renderer。下一步让开发者左键点选主视口中的物体，在同一 Inspector 中查看和修改当前 World 的实体。下文的拾取、选中反馈、帧率显示和配置预设是待实现功能。

## 窗口与输入

| 区域 | 行为 |
| --- | --- |
| 视口 | 保留当前整窗渲染。左键点可见网格选中，点背景清除。选中网格显示世界包围盒；从列表选中有限范围的灯时显示位置和范围。反馈画在调试层，避免进入 TAA 历史。 |
| 帧率与帧时间 | 在 Inspector 顶部显示主窗口的 FPS 和平均帧时间。每次主窗口成功提交呈现帧时用单调时钟取样。约每 0.5 秒用完整帧间隔数除以实耗时间计算 FPS，用实耗毫秒数除以间隔数计算平均帧时间。最小化时停止取样，恢复时重置。VSync 等待计入帧间隔。 |
| 对象列表 | 展开工具后按名称搜索、按组件过滤，可单独看灯光。无名称时显示组件类型和短标识。行有稳定的实体标识，筛选或排序保留选择。列表与视口共用选中实体。 |
| Inspector | 显示名称、可用的 GUID、父实体和已挂载的组件。可以改名、调整局部变换、调节灯光、替换资源引用及编辑数组。派生的世界变换和反射中标记为只读的字段显示为只读。 |
| Rendering | 集中显示渲染模式、实际生效状态、配置预设与恢复默认。显示活动灯总数，方向光、点光等按类型统计；仅在能获得已完成 GPU 时间戳时显示 GPU 耗时。 |

F1 切换 Inspector 及其帧率显示。保留右键捕获相机与 Esc 释放鼠标。鼠标按下时确定手势归属，释放时确认左键单击。字段编辑器优先处理 Enter 和 Esc，输入文字时屏蔽相机快捷键，拖动数值时由控件持有鼠标。窗口失焦时清除按键与捕获状态。

## 模块与数据所有权

- **Source/Editor** 的 SceneInspector 管理选中的 `hz::Entity`、选择序号和绑定的 World。列表、清空和视口点选共用选择入口。列表直接提供实体，Renderer 异步返回带请求序号的实体。Inspector 在当前 World 中复核 `IsAlive`。切换 World 时使旧请求失效并清空选择。
- **对象列表与 Inspector** 使用 World 查询和现有 `TypeRegistry`。首次打开列表时建立索引，以独立的 `WorldChangeLog` 消费变更；变换更新无需重排列表，仅名称、成员关系或搜索条件改变时更新对应行。日志溢出时重建。只为可见行生成文字，只对选中实体调用 `GetComponent`；组件内存仅在本次读取期间使用。字段绘制按 `PropertyKind` 分派，注册新组件即可得到通用展示。
- **Core CVar** 保存当前会话的配置值。命令行、面板和预设通过同一注册变量读写。Renderer 在主线程更新后读取本帧所需的值，结合设备能力决定实际执行的 pass。面板从 Renderer 取得执行结果。
- **Renderer 示例** 负责视口坐标换算、拾取命令和 GPU 资源。它用主渲染的 RenderContext 访问当帧场景数据，将结果解析为实体后交给 Inspector。独立窗口沿用自己的 D3D11 设备绘制 ImGui。主视口选中反馈另由工具叠加层承担。

## 组件编辑

- 控件按反射类型生成。枚举列出合法值，颜色与数值支持拖动预览，文本和引用在确认时提交。数组支持增删元素、调整长度及编辑元素字段。实体 GUID 等带有 `PROPERTY_READ_ONLY` 的字段遵守 World 的写入约定。
- 输入传递实体句柄、组件与属性 ID 及新值。主线程在 World 更新阶段应用变更，随后提取 RenderScene。单字段使用 `World::SetProperty`，数组使用 World 的数组编辑接口，使层级、资源绑定和渲染更新都能收到变更。每次提交复核实体和组件；数组结构变化时取消旧元素的待提交编辑。提交失败时在字段旁提示原因并回显 World 当前值。
- 对每帧由系统写入的属性，编辑同步到驱动该属性的状态。例如移动 Bistro 点光源时，将位置差加到运动锚点，保留相位和速度；改颜色、强度或范围直接更新该灯的 Light 组件。活动相机位姿编辑同步到相机控制器。灯被替换或切换 World 时结束对应编辑，待提交值随原目标失效。

## 点选如何工作

1. **记录请求。** 主视口确认左键单击时，按客户区实际显示矩形和 framebuffer 尺寸换算像素，记录 World、视口版本和新的选择序号。列表选择和清空也递增序号。缩放窗口或替换 World 时取消旧请求。
2. **画点击像素附近的几何。** 在处理请求的渲染帧，复用该帧的相机抖动、可见绘制列表、蒙皮结果与材质。用裁剪投影绘入小尺寸双通道整数目标和独立深度（例如 8×8）。目标像素与原视口像素一一对应，窗口边缘也保留正确偏移。alpha-mask 共用主渲染的裁剪函数，保留原屏幕像素坐标、像素奇偶对齐和 UV 导数，使栏杆孔洞与抖动裁剪一致。
3. **写入现有实例 ID。** 间接绘制用 `DrawId` 找到 draw 记录，再从其 `Object.x` 定位 GPU 实例表，输出该 `RenderInstance` 的完整 `RenderInstanceID`（index 和 generation）。背景清为无效 ID。透明渲染开启时，混合透明网格也参加深度测试和深度写入，关闭 ID 混合。按几何覆盖选最近表面，即使玻璃的混合 alpha 很低也可选中。关闭透明渲染时跳过这组网格。无网格实体从列表选择。
4. **在主提交之后执行。** 接入点为 Renderer 示例的 `RenderPasses::Execute()` 尾部。主渲染照常提交并 Present。有可用回读槽且存在有效请求时，才在同一图形队列追加独立的拾取命令列表。用小 compute pass 将点击像素的 8 字节 ID 写到 buffer，再用 `CopyBuffer` 复制到映射的回读槽。拾取只使用自己的输出目标。
5. **按最后一次 GPU 使用回收。** 普通帧沿用主提交句柄。点击帧用拾取的 `SubmitHandle` 更新帧槽的 `ConstantBuffer.Submission`，并传给 `GpuSceneData.EndFrame()`。共享的帧常量、绘制列表、蒙皮和场景资源必须覆盖此次提交，包括资源扩容或窗口重建时。回读槽按在途帧数预分配并记录各自的提交句柄。槽全忙时保留最新待处理请求。
6. **应用结果。** 后续帧轮询 `IsComplete`。仅当选择序号、World 和视口版本仍匹配时，才通过 RenderScene 的只读查询把完整实例 ID 解析为源实体。查询校验代际，支持无 GUID 实体。有效请求命中背景或已销毁对象时清空选择。过期结果直接丢弃。

这条路径的成本集中在点击帧的几何提交和顶点处理。小目标降低片元和存储成本，普通帧没有拾取绘制或回读，也无需增加全分辨率 GBuffer 附件。现有 GBuffer 的 Material ID 保留给材质使用。

## 渲染配置与比较

| 控件 | 生效约定 |
| --- | --- |
| Local lighting | `Clustered / Full light loop`。沿用启动时创建的 PSO；全量模式跳过构建 mask。分别展示所选模式和当前帧是否实际用了 mask。 |
| Ambient occlusion | `Off / GTAO / RT AO` 单选，对应 Renderer 当前两条互斥的 AO 路径。 |
| TAA、透明、RT 阴影、RT 反射 | 按现有 pass 能力接入。RT 不可用时禁选并给原因。影响时域结果的切换使对应 history 失效，切换后的第一帧从有效输入开始。 |
| VSync | 通过现有 `SetVSync` 在帧边界应用，显示实际结果；失败时保留原值并显示原因。 |
| 配置预设 | “项目默认”从各渲染 CVar 注册时的默认值恢复。“全量光照对照”只写入 `r.ClusteredLighting 0`，保留其余选项，用于同条件比较。 |
| 固定 Bistro 灯光现场 | 独立的示例调试控制，同时暂停移动和每秒替换，恢复时从暂停处继续。它允许在同一组灯和同一相机下比较两条光照路径，也方便跟踪单盏灯。 |

配置作用于当前运行会话。开发者可以随时恢复项目默认；面板开关和渲染预设各自独立。FPS 计入整帧，单个 GPU pass 的时间按最近已完成的时间戳展示，避免把两种口径混用。

## 交付与验收

先用两个共用网格和材质的实体打通视口点击、异步回读和组件编辑，验证帧槽复用与选择顺序。再验收透明、alpha-mask 和蒙皮，补上选中反馈。随后在 Inspector 顶部接入主窗口帧率，完成渲染配置预设和实际执行状态展示。

| 验收场景 | 预期结果 |
| --- | --- |
| 点击两个共用网格和材质的实体、栏杆孔洞和动画角色 | Inspector 分别显示对应实体、孔后可见实体和处理点击帧中该姿态的角色。点背景清空选择。 |
| 点击物体前的低透明度玻璃、重叠玻璃及被墙遮住的玻璃，再关闭透明渲染 | 依次选中玻璃、最近一层玻璃和墙；关闭后命中该像素仍可见的表面。 |
| 在 Inspector 改名、移动正在运动的灯并调整强度、修改材质覆盖数组 | 列表、画面和组件值反映成功提交的编辑；后续更新中灯围绕新的锚点运动。删除正在编辑的灯时，后继灯不会继承未提交的值。 |
| 选择某盏灯并等待每秒替换；连续点击 A、B，再点击列表 C | 灯被销毁时清空；复用实例槽或晚到的 A/B 结果都不能选错对象。 |
| 缩放 Windows 显示、调整窗口、最小化恢复、在搜索框输入 WASD | 命中像素正确，舍弃旧尺寸请求。恢复后重新累计主窗口帧间隔，输入文字时相机静止。 |
| 固定灯光和相机，切换 Clustered/Full、AO 和 TAA | 比较使用同一现场；全量帧无 mask dispatch；不支持的选项有原因；重新开启时没有旧 history 残影。 |
| 更改渲染配置后重启 Renderer | 重新加载项目默认渲染配置。 |
| 以 1080p 和 4K 分别采集关闭工具、打开 Inspector 和单次点击 | 记录空闲开销与点击尖峰。GPU capture 中普通帧沿用原 FrameGraph，点击帧在主提交之后出现一次独立拾取提交，CPU 异步读取结果。 |
